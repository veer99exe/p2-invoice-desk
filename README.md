# P2 Invoice Desk

CAP (Node.js) service + Fiori elements annotations. Reads the 200 newest supplier invoices from the S/4HANA
sandbox, adds seeded story invoices, runs checks D1–D4, computes a review priority, lets a clerk/manager record a
decision (stored in P4), and drafts the note with Groq (`openai/gpt-oss-120b`).

## Run it (in your Build trial dev space)
1. `npm install`
2. Check `.gitignore` has `.env` and `.cdsrc-private.json` (it does). Then:
   - copy `.env.example` to `.env` and fill the four P4 values + your Groq key
   - create `.cdsrc-private.json` with your sandbox key:
     `{ "requires": { "API_SUPPLIERINVOICE_PROCESS_SRV": { "credentials": { "headers": { "APIKey": "<your key>" } } } } }`
3. `cds watch`, open `/invoices/Invoices` (log in as `rita`/`rita` = APClerk, `carla`/`carla` = APManager).
4. `npm test` runs everything against fake servers: no keys needed.

| `test/` | P2-D1…D4, PR1…PR8, P2-R1…R3, G1…G4 |

## Verify these before you rely on it (I could not run them)
- **Project Accelerator (AC1):** the exam wants the first version generated by it. This project is the code to
  put on top. Run the Accelerator with the Requirements text, then merge: keep its `app/` folder, use
  `app/annotations.cds`, `db/schema.cds`, and `srv/` from here (or adapt names).
- **P4 contract:** I assumed P4 accepts `decision` = `Release` | `Keep Blocked` | `Escalate`, rootCause values as in
  the requirements text, the list endpoints `/Thresholds`, `/HoldList`, `/Suppliers`, `/InvoiceDecisions`, and the
  decision key `(source,SupplierInvoice,FiscalYear)`. Check once against P4 (S0 curl). If P4 requires a rootCause on
  Release, pick one in the dialog.
- **S/4 sandbox:** the fetch code uses plain HTTP with the APIKey header (no EDMX import). Run S0 first.
- **AI draft screen:** the action returns the text, but the "Use and save / Discard" dialog needs a small Fiori
  elements extension (not built). `confirmNote` is the Use-and-save call; Discard = do nothing.
- **G3 live:** the tests prove the planted text goes only as data with a "do not obey" rule. Whether the real model
  obeys it must be checked live on `DEMO-9001`; screenshot it.
